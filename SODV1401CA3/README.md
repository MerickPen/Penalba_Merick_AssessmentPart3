# Explore Alberta Trails

## Overview

This project was created for SODV1401 Competency Assessment Part 3.

The website demonstrates the use of third-party services, API integration, responsive design, SEO enhancements, privacy-conscious embedding practices, and Git version control workflows.

## Features

### Interactive Trail Map

The website includes an embedded OpenStreetMap iframe that allows users to view a trail location directly within the webpage.

### Live Weather Information

Current weather information is retrieved dynamically using the Open-Meteo API and the JavaScript Fetch API.

Weather information displayed includes:

- Temperature
- Wind Speed
- Weather Code

### Privacy Protection

The website includes several privacy-conscious measures:

- loading="lazy"
- referrerpolicy="no-referrer"
- sandbox restrictions on embedded content

### Performance Optimization

The project implements:

- Responsive image sizing
- WebP image support with JPEG fallback
- Lazy loading for media
- Minimal CSS and JavaScript
- Responsive layout design

### SEO and AIO

The website includes:

- Title tag
- Meta description
- Canonical URL
- Robots metadata
- Open Graph metadata

These elements improve discoverability for both search engines and AI systems.
